# Function Calendar

A lightweight planner, organizer, and calendar built with React and Vite. Navigate months, view a Sunday–Saturday grid, and add events with optional time ranges and notes.

## Features

- Create all-day or timed events, color-code them, and drag to reorder day priority.
- Pick multi-day ranges, add recurring events, and surface regional holidays.
- Sign up or log in (username/email + password) with local session cookies.
- Persist user-specific events and profile settings (theme, accent, time zone, region, profile image).
- Configure birthdays with automatic yearly reminders plus optional zodiac horoscopes and a live clock preference (12/24-hour).

## Development

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```
